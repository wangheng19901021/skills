# team-code-review：团队级审查规则模板

这是 `code-review-gate` 的团队扩展层。个人五关审查 Skill 管"AI 别犯通用错误"，这个目录管"我们团队踩过的具体坑"。

## 定位

- `code-review-gate/`：个人 Skill，放 `~/.claude/skills/`，跟着人走
- `team-code-review/`：团队规则，放项目根目录 `.claude/skills/`，跟着仓库走

Claude Code 两个位置都会扫描，所以每个开发者的 AI 会天然同时加载两套规则，不需要额外配置。

## 规则格式

每条规则必须标注来源——谁加的、踩了什么坑、什么时候加的。规则打架时，知道找谁聊。

```markdown
## 规则名
- 规则: 一句话说清必须怎么做
- 来源: 谁, 日期
- 触发: 什么线上事故让你写下这条规则
```

## 当前文件

- `concurrency.md`：并发与批处理场景的团队规则
- `security.md`：安全场景的团队规则
- `null-safety.md`：空指针场景的团队规则

现有内容是示例（来自我们组的真实踩坑），fork 之后请替换成你们团队自己的规则。

## 维护方式

```
线上炸了 → 排查 → 确认根因是不是现有规则能兜住的
不能 → 在对应文件里加一条，标注来源和日期
→ git commit + push → 所有人的 AI 下次自动生效
```

不靠 Confluence，不靠周会分享，不靠"下次注意"。靠 AI 每次都读。
